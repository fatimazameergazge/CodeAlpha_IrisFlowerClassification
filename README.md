# 🌸 Iris Flower Classification

## Overview
A machine learning project that classifies Iris flower species 
(Setosa, Versicolor, Virginica) based on their measurements 
using the K-Nearest Neighbors (KNN) algorithm.

## Dataset
- Source: Sklearn built-in Iris Dataset
- 150 samples, 3 classes
- Features: Sepal Length, Sepal Width, Petal Length, Petal Width

## Model
- Algorithm: K-Nearest Neighbors (KNN)
- Test Size: 20%
- **Accuracy: 100%**

## Results
- Perfect classification of all 3 species
- Confusion matrix shows zero misclassifications

## Tools & Libraries
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## How to Run
1. Open `Iris_Classification.ipynb` in Google Colab
2. Run all cells top to bottom
3. No dataset download needed — loads automatically!
